# 🎮 DSS Gymnasium RL | DSS 强化学习环境

> **Custom Gymnasium reinforcement learning environment for Decision Support Systems (DSS). Train RL agents for sequential decision-making, resource allocation, and optimization tasks. Compatible with Stable-Baselines3 and other RL frameworks.**
>
> 面向决策支持系统（DSS）的自定义 Gymnasium 强化学习环境。训练 RL 智能体进行序列决策、资源分配和优化任务。兼容 Stable-Baselines3 等 RL 框架。

---

## 🌟 Features | 核心特性

- **Gymnasium API** — Standard Gym/Gymnasium interface
- **Decision Support** — RL environment for DSS scenarios
- **Multi-Agent** — Support for multi-agent settings
- **Customizable** — Easy to modify reward, state, action spaces
- **Compatible** — Works with Stable-Baselines3, RLlib, etc.
- **Visualization** — Built-in rendering and logging

---

## 🚀 Quick Start | 快速开始

```bash
pip install gymnasium stable-baselines3

# Train an agent
python train.py --algo ppo --timesteps 100000

# Evaluate
python evaluate.py --model best_model.zip
```
